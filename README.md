Node.js 24 + React + SQLite. Set EDITOR_PASSWORD, SESSION_SECRET; npm ci --include=dev; npm run build; npm start.

ผู้ชมอ่านได้ ผู้แก้ไขใช้รหัสระบบทดสอบ. ลบแบบ soft delete. ข้อมูลตัวอย่างสร้างครั้งเดียวผ่าน app_migrations. Unique number per calendar year, pending entries last. Singapore Free web service, no paid database or disk. SQLite is ephemeral: changes are lost on Render spin-down, restart or redeploy. The page displays this restriction and offers JSON backup including deleted rows. Do not enter production data. Run TEST_URL and TEST_PASSWORD with node verify.mjs to check CRUD on a fresh three-row instance.
